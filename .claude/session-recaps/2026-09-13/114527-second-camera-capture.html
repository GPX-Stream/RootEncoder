Design

Key Decisions

›
  • Two Camera2ApiManager instances, not new open/close code. Every piece of its state is per-instance already — reusing the class satisfies the "second concurrent open path" and "bounded-open/generation-guard" asks for free.
  • CameraRender's output is a plain GL_TEXTURE_2D — ScreenRender samples it generically, so a second CameraRender's texture is directly usable by the same ScreenRender without duplicating crop/rotate/aspect logic.
  • Secondary pipeline is fully lazy — nothing allocated until a caller calls getSecondarySurfaceTexture()/getSecondarySurface(), preserving byte-for-byte identical cost when unused.
  • Preview, multi-preview, photo stay on primary — Decision 4 names only stream/record; extending to photo (mirroring fork change 8/9's overlay precedent) was considered and deliberately not done, to avoid scope creep.
  • OpenGlView throws, doesn't silently no-op, on the two new getters — a dummy object nothing updates would hide a real failure.

Gotchas

›

local.properties in a fresh worktree

First build failed with "SDK location not found" until the gitignored local.properties was copied in from the main checkout — the worktree-workflow rule wasn't optional here.

git add on tracked-but-gitignored docs

.claude/gpx-branch-policy.md sits under a root /.claude gitignore pattern despite being tracked. Plain `git add` refuses it; `git add -u <path>` is the right fix, not `-f`.
